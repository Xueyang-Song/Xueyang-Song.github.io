# Xueyang Song Personal Site

Astro static site for Xueyang Song's personal research profile and product homes for Paper Pilot and AcademiaML.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run test
npm run build
```

## Cloudflare Pages

- Build command: `npm run build`
- Output directory: `dist`
- Node.js: `22`

Paper Pilot resolves the latest Windows x64 installer through GitHub Releases. Unreleased apps keep their download actions disabled.
